# X2Griffon (X2 Griffin)

Lightweight (~1 lb) high-altitude balloon payload platform developed by **Midwest Stratospheric Data Systems**.

Designed for near-space (75k–125k ft) and mid-tropospheric research flights with rapid recovery and open data release.

## Platform Overview

X2Griffon integrates:

- Reprogrammed RS-41 radiosonde (70cm / 2m)
- U4B WSPR telemetry
- BTECH APRS-K1 PRO tracking
- Dual-camera stratospheric imaging system
- Custom lightweight Midwest-manufactured structure and electronics

Evolved from earlier AmUP01 / MAD-AP prototypes.

## Goals

- Collect high-quality atmospheric data (temperature, humidity, wind profiles, imagery)
- Public release of data with <48-hour turnaround
- Support open science, tornado research, environmental monitoring, and education
- Reliable, affordable, DIY-friendly yet professional-grade HAB technology made in the Midwest
